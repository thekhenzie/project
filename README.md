# project.khendaniel.com

Small single-page tools, hosted on GitHub Pages at **https://project.khendaniel.com**.

| Page | URL |
|---|---|
| Worlds 2026 Pick Board | https://project.khendaniel.com/2026-pickems/ |
| Will the Bed Fit? | https://project.khendaniel.com/bed-fit/ |
| Habit Chain | https://project.khendaniel.com/habit-chain/ |

Each page is one self-contained `index.html`, with no build step. Anything you enter is saved in your own browser (`localStorage`). Nothing is sent to a server.

To add a page, create a new folder with an `index.html`, link it from the root `index.html`, and push.
